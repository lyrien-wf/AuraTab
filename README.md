# AuraTab

> 把收藏夹变成你的浏览器主页。

AuraTab 是一个轻量的 Chromium 浏览器扩展（Manifest V3），接管浏览器的**新标签页**：左侧是你的收藏夹目录树，中间是时钟与搜索框，下方是当前目录的书签卡片。每次打开新标签页，都像一个属于自己的网页门户。

## 功能亮点

- 🗂️ **书签即主页** —— 目录树展示所选收藏夹根的全部层级；右侧只展示当前目录的直接书签，结构清晰、绝不混乱平铺
- 🔍 **双职责搜索** —— 输入关键词实时过滤本地书签；`?` 前缀直达搜索引擎；点击搜索框左侧的引擎图标即可在 Bing / Google / 百度 / 自定义之间一键切换
- 🕐 **时钟与日期** —— 24 小时制、秒、日期显示均可配置
- 🎨 **外观灵活** —— 浅色 / 深色 / 跟随系统主题；每行卡片数自动或固定 6 / 8 / 10；侧栏宽度可拖拽并记忆；窄窗口自动切换为抽屉模式
- ⚡ **快** —— 一次读取全树、索引查表切换目录、快照预渲染消除白屏，大目录（300+ 书签）自动启用虚拟滚动
- 🔄 **实时同步** —— 在浏览器任何位置增删改书签，已打开的主页自动刷新，选中的目录保持不变
- ⌨️ **键盘友好** —— 目录树完整键盘导航（↑↓←→/Enter/Home/End），`/` 聚焦搜索，`Esc` 清空
- 🔒 **零收集、零上传** —— 代码中不存在任何网络请求，仅申请 `bookmarks` / `storage` / `favicon` 三个权限

## 安装

尚未上架扩展商店，需自行构建后加载（一次性操作，约一分钟，需要 Node.js 18+）：

```bash
git clone https://github.com/lyrien-wf/AuraTab.git
cd AuraTab
npm install
npm run build     # 构建产物输出到 dist/
```

然后把 `dist/` 文件夹加载进浏览器（要求 Chromium 内核 114+）：

- **Edge**：打开 `edge://extensions` → 开启「开发人员模式」→「加载解压缩的扩展」→ 选择 `dist/`
- **Chrome**：打开 `chrome://extensions` → 开启「开发者模式」→「加载已解压的扩展程序」→ 选择 `dist/`

打开一个新标签页即可使用。🎉

## 隐私承诺

**不收集、不上传任何数据，没有后端服务。**

- 整个扩展没有任何网络请求代码（无 `fetch` / `XMLHttpRequest`），唯一的"出网"是你主动按 Enter 跳转搜索引擎
- 书签数据只在浏览器本地内存与 `chrome.storage` 中流转；设置项通过浏览器自带的账号体系（`storage.sync`）跨设备同步
- 站点图标读取浏览器本地 `_favicon` 缓存，不请求第三方图标服务
- 严格 CSP、不使用 `eval`；打开链接前校验协议，始终拦截 `javascript:` 等伪协议书签
